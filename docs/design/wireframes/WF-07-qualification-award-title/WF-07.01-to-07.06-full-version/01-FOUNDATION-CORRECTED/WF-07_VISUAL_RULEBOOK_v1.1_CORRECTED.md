# WF-07 VISUAL RULEBOOK v1.1

Material Design-inspired enterprise wireframe. Desktop and mobile are separate targets. Navigation can collapse/hide/show and is never authorization. Vertical scroll is preferred to cramped layouts. Dynamic text wraps. Dense admin operations are split into coherent screens. Progressive disclosure is used for evidence payload, historical snapshot and provenance.

Responsive: desktop 1440×1024; mobile 390×844; content-driven breakpoints. Mobile converts dense tables to cards/lists.

Accessibility: keyboard focus, semantic hierarchy, accessible names, non-color-only state, approximately 44×44 touch targets, screen-reader status, reduced motion.
