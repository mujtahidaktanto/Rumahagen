# WF-09 State Coverage
Where applicable: Loading, Empty, Ready, Pending, Success/Confirmed, Rejected, Failed, Expired, Unauthorized, Protected non-existence, Retry/Recovery, Offline/Interrupted.
M13 operational states additionally distinguish UNVERIFIED, VALID/ACTIVE, INVALID/ERROR, DISABLED, REVOKED, DISCONNECTED, DELETED and temporary provider outage.
Webhook states distinguish Delivered/Pending/Failed/Duplicate-Idempotent.
Reconciliation distinguishes Open/Resolved.
Authoritative server state remains source of truth.
