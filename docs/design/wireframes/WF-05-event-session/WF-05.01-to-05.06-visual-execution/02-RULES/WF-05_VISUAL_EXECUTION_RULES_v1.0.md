# WF-05 Visual Execution Rules v1.0

- Modern Material Design-inspired enterprise UI.
- Canonical RumahAgen logo on every visual target.
- Desktop and mobile are separate surfaces.
- Shared WF-00 shell; navigation is collapsible and never an authorization boundary.
- Vertical scrolling is allowed.
- Progressive disclosure is used for secondary provider/configuration details.
- No invented business character limits.
- Dynamic text wraps; operational collections support pagination patterns.
- State handling includes loading, empty, validation, error, retry, success, denied where applicable.
- Authoritative outcomes are not shown optimistically.
- 13 Create Listing fields remain WIRE-02/M03 and are not duplicated into WF-05.
