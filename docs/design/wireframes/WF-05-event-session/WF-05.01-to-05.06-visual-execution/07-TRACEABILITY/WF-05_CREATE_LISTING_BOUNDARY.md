# Create Listing Cross-Package Boundary

The 13 Core-required Create Listing fields are intentionally NOT duplicated in WF-05. They remain WIRE-02/M03-owned.

Event fields with similar labels are different semantics: Event title != Listing title; Event category != Listing category; Event location != Listing address. Guest email is a contact/notification destination, not canonical identity. Related Project is contextual only and does not transfer Listing authority.
