# WF-05 Visual Execution Rules v1.1

- Integrated Core shell; canonical RumahAgen logo on every visual target.
- Desktop and mobile are separate outputs.
- Mobile never preserves desktop two-column field layouts when they cause collision.
- Required/in-scope fields remain available on mobile; secondary details may use progressive disclosure but may not be silently dropped.
- Vertical scroll is explicitly permitted.
- Long text wraps; no invented business character limits.
- Operational collections retain search/filter/pagination affordances.
- Event Registration is distinct from Session Enrollment.
- M05 owns Event/Registration semantics; M04 remains Session/evidence authority.
- Provider state is shown without claiming automatic runtime failover.
- Authoritative outcomes are not optimistic.
- Navigation visibility is not an authorization boundary.
- Accessibility baseline: semantic labels, visible focus, no color-only status, touch target approximately 44x44 CSS px.
