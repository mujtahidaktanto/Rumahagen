## Admin/partner scope
ADM-LRN-001 Course Management; 002 Course Details Editor; 003 Lesson Manager; 004 Quiz Manager; 005 Learning Path Management; 006 Learning Activity Management; 007 Learning Economy Configuration; 008 LP Adjustment; 009 Assessment Review/Grade/Validate; 010 Skill Management; 011 Credential Management; 012 Learning Reconciliation; 013 Partnership Learning Result.

## Boundary corrections
Partnership Learning discovery/access is represented within LRN-001/LRN-002 rather than creating unnecessary screens. Activity completion is not shown as authoritative until the authoritative outcome is returned. LP reward follows qualifying completion as a governed consequence. LP purchase remains M14/WIRE-06. Skill is not Competency; Credential is not M15 Award/Title. Detailed Session management remains WIRE-05.

## Listing boundary
Create Listing fields remain WIRE-02/M03. WIRE-04 does not duplicate the 13 required Create Listing user-facing inputs. Any learning-to-listing relationship must be represented only as a controlled cross-module handoff if later evidenced; no Listing form is added here.
