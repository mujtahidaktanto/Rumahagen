# WIRE-04 Visual Wireframe Rules v1.1

Material-inspired, restrained enterprise UI. Use the canonical RumahAgen logo supplied with the upload.

Desktop shell: top app bar + collapsible sidebar + breadcrumb/context + title/action + scrollable content. Mobile: compact top bar + menu + stacked content. Navigation hide/show is visual convenience only and never an authorization boundary.

Use progressive disclosure, drawers/modals and wizards when they reduce cognitive load. Do not force all requirements into one screen. Use vertical scrolling rather than shrinking typography/components.

Typography hierarchy: Display/H1/H2/H3/Body/Body Small/Caption/Label/Numeric Emphasis. Dynamic text wraps; no unsupported hard character limit is invented.
