# Create Listing Boundary
The 13 Core-required user-facing Create Listing inputs remain WIRE-02/M03:
listing_context, category, transaction_type, title, property_type, price, is_negotiable, address, province, city, district, dispute_free_declared, whatsapp_number.

WF-08 does NOT duplicate these fields. Their semantic, dependency, requiredness, conditionality and input UX remain M03/WIRE-02. WF-08 represents authorization around Listing actions only.
