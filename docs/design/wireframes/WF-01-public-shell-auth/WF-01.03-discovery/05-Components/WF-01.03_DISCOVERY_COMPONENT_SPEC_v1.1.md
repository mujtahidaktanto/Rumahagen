# WF-01.03 Discovery Component Specification v1.1

## Shared components
- WF-01.01 Global Public Shell
- Search field
- Filter/sort controls
- Active filter chips
- Result collection
- Loading skeleton
- Empty/no-results state
- Error + Retry
- Pagination or infinite scroll where appropriate
- Protected-resource-safe unavailable state

## Screen-specific component composition
| Screen | Required semantic blocks |
|---|---|
| PUB-02 | Result-type indicator, title, summary, domain context, open-detail CTA |
| PUB-03 | Listing media, title/location, price, property facts, public state, detail CTA |
| PUB-05 | Agent avatar/identity, location/specialty, review/outcome summary, public CTA |
| PUB-07 | Organization identity/logo, overview, public member/listing summary, CTA |
| PUB-09 | Developer identity, Project title, approved media, project facts, CTA |
| PUB-11 | Event identity, date/time, format/location, availability indicator, registration entry |
| PUB-13 | Learning identity, path/type/level, commercial/free indicator if authoritative, eligibility/entry |

The components are presentation-only. They do not create business authority, lifecycle mutation or
administrative controls.
