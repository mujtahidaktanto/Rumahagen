# WF-01.03 Discovery States v1.1

Every discovery screen supports, as applicable:
- Loading
- Ready
- Empty / No results
- Error
- Retry
- Unavailable / non-public

Additional rules:
- Filter state is explicit and removable.
- No-results is not represented as system failure.
- Long title/description wraps without destroying hierarchy.
- Mobile uses stacked content and vertical scroll.
- Protected/non-existent resources do not reveal protected existence.
- Indexability and visibility never imply authorization.
- Domain-specific unavailable states use source semantics rather than inventing lifecycle states.
