# WF-01.05 Authentication States v1.1

## AUTH-01 Registration
Untouched → Dirty → Valid/Invalid → Submitting → Server Error → Success → OTP verification.

## AUTH-02 OTP Verification / Activation
Waiting → Invalid → Expired → Verifying → Success.
Success means:
`OTP VERIFIED → ACCOUNT ACTIVE`.

No Pending Review activation state is inserted.

## AUTH-05 Login / Session
Empty/validation → Invalid Credentials → Submitting → Session Established → Session Expired / Failure.
Authorization denial is a post-auth state, not an authentication authority.

## AUTH-06 Recovery / Reset
Request → Sent → Invalid/Expired recovery path → New password → Success / Failure.

## KTP boundary
KTP Deferred and KTP Completion states belong to WF-01.06. WF-01.05 only hands off after authentication.
