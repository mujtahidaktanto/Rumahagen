# WF-01.05 Traceability v1.1

| Source | Representation |
|---|---|
| M01 | Registration, OTP, ACTIVE lifecycle, login/session, recovery |
| M01 KTP contract | Explicitly preserved as deferred downstream boundary |
| WF-01.00 | AUTH-01, AUTH-02, AUTH-05, AUTH-06 allocation |
| WF-01.06 | AUTH-03 and AUTH-04 downstream |
| M10 | Authorization after authentication; no RBAC invention |

Critical trace:
`Register → OTP verification → ACTIVE → general authenticated entry`
while authorization remains role/permission/scope/condition controlled.

Critical non-propagation:
`KTP ≠ permission`, `OTP success ≠ unrestricted capability`,
`PENDING_REVIEW` is not an M01 activation gate.
