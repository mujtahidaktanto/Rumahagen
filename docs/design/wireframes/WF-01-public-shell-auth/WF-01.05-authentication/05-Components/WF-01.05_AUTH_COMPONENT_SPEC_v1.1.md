# WF-01.05 Authentication Component Specification v1.1

- Authentication shell
- Labeled fields
- Password/recovery controls
- OTP input (6-digit conceptual input) with resend/retry
- Primary action
- Inline validation
- Loading/submitting
- Server error
- Success transition
- Session status messaging

AUTH-02 must visually communicate the authoritative success contract:
`OTP VERIFIED → ACCOUNT ACTIVE`.

It must not visually imply:
`OTP VERIFIED → PENDING_REVIEW → ACTIVE`.

KTP controls are not rendered as part of the activation screen; the downstream handoff is to WF-01.06.
