## Screen-specific public detail architecture

### PUB-04 — Listing Detail
Media/gallery → title/location → price → core property facts → public description → eligible contact CTA →
related public listings. M03 remains Listing lifecycle/content/media/refresh authority. No management controls.

### PUB-06 — Agent Public Profile
Agent identity/profile header → public bio/specialties → public review/outcome presentation where eligible →
public/WhatsApp CTA where eligible → related public listings. Protected identity/verification data is excluded.
Review moderation is not exposed here.

### PUB-08 — Organization Public Profile
Organization identity/logo → public overview → public member/listing summary where eligible → public content/
listings → public contact/CTA. Membership lifecycle and organization administration are excluded.

### PUB-10 — Developer / Project Detail
Developer identity/logo → Project media → project overview → canonical project fields → approved related
Listings → public CTA. Project Claim/admin operations are excluded. Project Media remains photo/video; Marketing
Kit remains a distinct resource and is shown only when public/eligible.

### PUB-12 — Event Detail
Event identity → date/time → venue/format → description → availability/quota indicator where authoritative →
registration CTA → related events. Event Registration, waitinglist mutation and attendance operations are
downstream and are not managed here.

### PUB-14 — Learning Session Public Detail
Session identity → schedule → Host and Instructor as distinct concepts where present → description →
visibility/eligibility → enrollment/access CTA → related learning. Session management, attendance, completion and
Learning Economy transactions are excluded.

### PUB-15 — Static Public Content
Breadcrumb/title → published body → supporting media/links → related public content → share/SEO. This is the
public representation only; authoring/configuration/lifecycle mutation is outside the screen.

### PUB-16 — Announcement / Promotion Public Detail
Public header → image → public copy → schedule/context → configured CTA → related public content →
dismissible behavior. Administrative configuration remains outside this screen.

## Shared public-detail rules
Visibility ≠ authorization. SEO/indexability ≠ authorization. Public detail never exposes protected data.
Canonical URL, metadata, structured data and indexability are derived from canonical source state.
