# WF-01.04 Detail Component Specification v1.1

## Shared
- WF-01.01 Global Public Shell
- Detail header
- Primary media/content region
- Semantic metadata region
- Eligible primary CTA
- Share/SEO representation
- Related/supporting public information
- Loading skeleton
- Empty / unavailable
- Error + Retry
- Optional media absence/failure handling

## Screen-specific blocks
- PUB-04: Listing gallery, title/location, price, property facts, description, contact CTA, related Listings.
- PUB-06: Agent identity, public bio, specialties, review/outcome presentation, WhatsApp/contact CTA,
  related public Listings.
- PUB-08: Organization identity/logo, overview, eligible public member/listing summary, public content/listings.
- PUB-10: Developer logo/identity, Project media, Project overview, canonical fields, approved related Listings,
  eligible public Marketing Kit reference.
- PUB-12: Event identity, schedule, venue/format, availability/quota indicator, registration entry.
- PUB-14: Session identity, schedule, Host, Instructor, description, eligibility, enrollment/access entry.
- PUB-15: Breadcrumb, title, body, media/links, related content, share/SEO.
- PUB-16: Announcement header, image, copy, schedule/context, configured CTA, related content, dismissible UI.

No component creates domain lifecycle authority.
