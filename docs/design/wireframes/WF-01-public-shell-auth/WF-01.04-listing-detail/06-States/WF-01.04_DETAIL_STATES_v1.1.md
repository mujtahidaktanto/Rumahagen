# WF-01.04 Detail States v1.1

Global states:
- Loading
- Ready
- Empty
- Error
- Retry
- Unavailable where applicable

Rules:
- Optional media absence never collapses the semantic hierarchy.
- Long text wraps and remains readable; vertical scroll is normal.
- Protected/non-existent resources must not leak protected existence.
- CTAs are rendered only when source eligibility permits.
- Irreversible outcomes are never shown optimistically.
- Public review/outcome information is shown only when its source visibility contract permits.
- Event availability is informational; registration mutation is downstream.
- Learning Session visibility/eligibility is distinct from authorization.
- Static Content and Announcement/Promotion are public representations, not admin editors.
