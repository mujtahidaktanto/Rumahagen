# WF-01.01 — Global Public Shell Component Specification v1.1

## Purpose
Establish the reusable public shell for WIRE-01. This is a layout/interaction realization of the current Core contract; it creates no new business semantics.

## Desktop
- Top app bar: canonical RumahAgen logo, global public search, menu/drawer control, authentication entry.
- Public navigation is available through a collapsible/hidden drawer.
- The drawer exposes the ten mandatory public discovery surfaces without requiring the user to understand modules.
- Main content uses a readable max-width and vertical scroll.
- Primary action is visually dominant but limited.
- Footer remains concise.

## Mobile
- Compact top bar: logo, search, menu, authentication entry.
- Primary navigation uses menu/drawer and a compact high-frequency navigation pattern.
- Content stacks vertically.
- No horizontal overflow.
- Sticky primary CTA may be used only where it improves task completion.

## Navigation semantics
- Hiding/collapsing navigation changes presentation only.
- Navigation is not authorization.
- Public discovery does not grant access to protected resources.
- Authentication state changes the available shell variant but does not create business authorization.

## Context
- Public shell does not force Organization context.
- Authenticated context switching belongs to later authenticated shell work.

## Source boundary
The only visual brand asset used is the uploaded RumahAgen logo. Exact colors/spacing remain design-system implementation details unless frozen by the Core.


## Canonical public surface labels
The reusable navigation uses the exact current Core terminology: Homepage; Listing; Agent; Organization; Developer / Project; Event; Learning; Learning Session; Static Public Content; Announcement / Promotion. These are presentation labels only and do not create authority.
