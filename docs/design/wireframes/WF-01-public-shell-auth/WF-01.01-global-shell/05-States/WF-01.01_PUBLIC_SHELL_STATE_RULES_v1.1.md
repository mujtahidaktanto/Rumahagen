# WF-01.01 — Public Shell State & UX Rules v1.1

- Loading: shell chrome renders without implying loaded data.
- Search loading: show progress without presenting false results.
- Search empty: actionable empty state with a clear alternative action.
- Search error: explain failure and provide Retry.
- Menu open/closed: preserve context and scroll position.
- Long navigation labels: wrap safely; never clip meaning-critical labels.
- Long page titles: allow multi-line headings.
- Mobile: vertical scroll is normal; do not shrink typography to eliminate scroll.
- Offline/interrupted: retain shell and expose recoverable state where applicable.
- Protected/non-existent public resource: do not leak protected resource existence.
- Authentication error: keep the user in the authentication flow with actionable recovery.
