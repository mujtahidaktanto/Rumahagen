# WF-01.06 States

AUTH-03:
- Active + KTP outstanding
- Complete now
- Deferred: `DEFERRED / NOT_PROVIDED`
- action failure + retry

AUTH-04:
- empty
- validation error
- invalid document
- processing/upload
- review-ready
- submitting
- submission error + retry
- submitted confirmation

`PENDING_REVIEW` is not introduced as an M01 activation state.
Protected document data/existence is not exposed publicly.
