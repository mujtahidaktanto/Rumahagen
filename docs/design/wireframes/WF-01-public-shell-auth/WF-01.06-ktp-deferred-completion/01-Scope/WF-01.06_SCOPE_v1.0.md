# WF-01.06 Scope

## In scope
AUTH-03 KTP Deferred Decision; AUTH-04 KTP Completion / Verification Document Submission.

## Out of scope
Registration/OTP/login/recovery (WF-01.05); Agent profile management; Admin review/moderation UI;
RBAC management; physical API/database/RLS implementation; invented endpoint/role/permission/schema.

## Screen allocation
No extra logical screens are created. AUTH-04 is a progressive wizard:
1. KTP details
2. Verification document
3. Review & submit

The wizard is a UX decomposition, not a new authority or separate domain screen.
