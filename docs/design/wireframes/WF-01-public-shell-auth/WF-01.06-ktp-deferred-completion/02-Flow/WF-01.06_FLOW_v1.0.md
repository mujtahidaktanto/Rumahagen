# WF-01.06 Flow

```text
OTP VERIFIED
    ↓
ACCOUNT ACTIVE
    ↓
KTP requirement evaluated independently from RBAC
    ↓
AUTH-03 — KTP Deferred Decision
    ├── Complete now → AUTH-04
    │                    ├── Step 1: KTP details
    │                    ├── Step 2: Verification document
    │                    └── Step 3: Review & submit
    │
    └── ISI NANTI → DEFERRED / NOT_PROVIDED
                     ↓
                  Continue in ACTIVE account
```

Invalid document → reject file + retain form.
Submission error → actionable retry.
Successful submission does not re-run account activation.
