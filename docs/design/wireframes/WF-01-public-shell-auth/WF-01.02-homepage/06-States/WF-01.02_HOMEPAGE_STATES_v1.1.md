# WF-01.02 — Homepage States v1.1

- Loading: shell/structural placeholders without false business claims.
- Ready: public discovery entries and eligible public content render.
- Empty: concise actionable empty state.
- Error: explanatory error with Retry; unrelated public navigation remains usable.
- Announcement absent: omit the announcement block; never fabricate content.
- Static content absent: omit or show neutral empty state where the slot is explicitly present.
- Long labels/text: wrap and allow vertical scrolling.
- Mobile: stacked layout; no horizontal overflow.
- Accessibility: semantic headings, accessible names, visible focus, sufficient targets, no color-only status.
- Public discovery never implies authorization.
