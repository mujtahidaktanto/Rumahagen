# WF-01.02 — Homepage Component Specification v1.1

1. Reuse WF-01.01 public shell.
2. Primary public search/discovery area.
3. Ten-surface public discovery entry model.
4. Conditional Announcement/Promotion slot.
5. Conditional Static Public Content entry.
6. Concise footer.

Announcement/Promotion is rendered only when there is an active public item; V1 semantics remain scheduled, dismissible and non-segmented. Static Public Content is a public representation; lifecycle/configuration remains with M09/applicable owner.

No personalized recommendation, featured-listing algorithm, arbitrary marketing headline, ranking rule, or commercial offer is invented.


## Homepage SEO / discovery contract
SEO behavior is a non-visual contract, not an additional screen: public/indexability follows authoritative state; Homepage has one canonical URL; supported metadata including Open Graph/Twitter where applicable follows the current SEO contract; sitemap and robots/indexability semantics are respected; no private/sensitive data is exposed; analytics remains observational and non-authoritative.
