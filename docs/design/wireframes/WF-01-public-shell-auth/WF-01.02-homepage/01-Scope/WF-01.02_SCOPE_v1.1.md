# WF-01.02 — Homepage Scope v1.1

## In scope
- Homepage as the canonical M11 public discovery surface.
- Public search/discovery entry.
- Reachable entry points to all ten mandatory M11 public surfaces.
- Conditional public Announcement/Promotion slot.
- Conditional Static Public Content entry.
- Reuse of WF-01.01 Global Public Shell.
- Desktop/mobile responsive realization, vertical scroll, dynamic text and states.

## Out of scope
- Detailed Listing results/detail, Agent detail, Organization management, Developer/Project management, Event registration/session operations, Learning Economy operations, content/promotion administration, authentication screens, admin/system/commercial screens.

## Anti-invention rule
The current Core does not prescribe a specific marketing headline, featured-listing algorithm, personalization model, or banner placement. The wireframe therefore uses neutral structural labels and conditional source-backed slots rather than invented business content.
