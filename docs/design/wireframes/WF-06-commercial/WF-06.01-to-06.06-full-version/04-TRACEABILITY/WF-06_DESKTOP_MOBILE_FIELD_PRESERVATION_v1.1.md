# Desktop/Mobile Required-Field Preservation Rule v1.1

1. Every material field marked required/conditional in the M14 semantic matrix must remain available on mobile.
2. Mobile uses stacked fields, cards, drawers, accordions and vertical scroll rather than deletion.
3. Search/filter controls may move into a filter drawer but remain discoverable.
4. Provider/configuration details may use progressive disclosure but cannot be semantically removed.
5. Payment status states remain fully visible on mobile.
6. Quota chain remains explicit: Capacity → Pool → Allocation → Usage → Remaining.
7. Long text wraps; no invented character limits.
8. Touch targets target approximately 44×44 CSS px; keyboard/focus/labels/contrast follow WCAG 2.2 AA-oriented baseline.
