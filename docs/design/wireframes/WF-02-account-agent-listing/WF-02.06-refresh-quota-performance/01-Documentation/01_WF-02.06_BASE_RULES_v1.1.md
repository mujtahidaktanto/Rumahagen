# WF-02.06 Base Wireframe Rules — v1.1

WF-02.06 remains a controlled client wireframe slice under the Integrated Core Master Wireframe baseline.

## Scope and boundaries
- Exactly three logical screens: AGT-013 Refresh Listing, AGT-016 Listing Quota / Capacity, AGT-017 Listing Performance.
- AGT-013: M03 Refresh action/enforcement, M14 configurable commercial allowance, M10 authorization.
- AGT-016: M14-owned commercial quota/capacity presentation only.
- AGT-017: projection/presentation of authoritative Listing activity; no mutation or analytics administration.
- Do not absorb WF-02.05 screens or later WIRE packages.

## WF-00 compliance
- Desktop/mobile are separate deliverables.
- Navigation may hide/show/collapse and is never an authorization boundary.
- Vertical scrolling is explicitly allowed and preferred.
- Dynamic real-world text and large numeric values must wrap/reflow safely.
- No unsupported business character limits are invented from physical storage lengths.
- Accessibility is WCAG 2.2 AA-oriented: semantic headings, labels, focus, keyboard/touch operation, non-color-only status and accessible chart summaries.

## Authority and state
- UI presents authoritative domain state; it must not optimistically declare mutation success or fabricate entitlement values.
- State coverage remains Loading, Ready, Empty/Zero Data, Error/Retry, Protected, Offline/Interrupted plus applicable action-specific states.
- Physical DB, migration, API runtime, RLS, runtime authorization, integration and production proof are **NOT WIREFRAME BLOCKERS**. Only unresolved semantic, authority or UX contradictions may block a WIRE package.

## v1.1 controlled corrections
1. AGT-016 separates Total, Allocated, Used and Available.
2. AGT-013 separates configured daily allowance, Used today and Remaining today; the default value 5 is not presented as a hard-coded permanent remaining balance.
3. AGT-017 separates CTA clicks and Leads.
4. Current Core provenance is updated to the Core (6) reconciliation target.
5. Mobile ready states were reflowed to avoid clipped labels/overflow and action overlap; this preserves WF-00 responsive/dynamic-content rules.
