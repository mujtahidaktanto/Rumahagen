# Dynamic Content / Responsive Rules — v1.1

- Titles, locations, labels, messages and metric values wrap safely.
- No unsupported maximum business character limit is introduced.
- Desktop may use multi-column metric cards; mobile converts dense metrics into stacked cards to preserve readable labels.
- Vertical scrolling is expected for long screens.
- Action buttons must not overlap explanatory text at mobile widths.
- Charts require an accessible text summary/equivalent representation.
- Status is not conveyed by color alone.
- Data-heavy future implementations use bounded pagination/infinite-scroll patterns where appropriate; wireframes do not compress content to avoid scrolling.
