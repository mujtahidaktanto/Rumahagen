# WF-02.01 Cross-Module Continuity

Dashboard → Listing
- AGT-001 can link to Listing management, but does not own Listing truth.

Dashboard → Learning / Event / Commercial / Organization / Awarding
- Cards are projections only.
- Destination remains owned by its authoritative WIRE/module.

Dashboard → Notifications
- Notification entry follows M08 projection semantics.
- It cannot bypass M10 or source-domain visibility.

Profile → Public Agent Profile
- Private authenticated profile and public profile are related but distinct presentations.
- Public visibility/CTA remain M02-owned.

Profile → KTP
- KTP is not rendered as a public profile field.
- KTP requirement/eligibility remains upstream M01 flow.

Navigation → Authorization
- Hide/show navigation changes presentation only; M10 remains authorization authority.
