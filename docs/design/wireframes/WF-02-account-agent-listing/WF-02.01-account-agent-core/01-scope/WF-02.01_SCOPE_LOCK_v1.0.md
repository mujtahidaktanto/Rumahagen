# WF-02.01 Scope Lock v1.0

## Objective
Realize only the authenticated **Account + Agent Core** surface:
- AGT-001 Agent Dashboard
- AGT-002 Agent Profile

## Authority
- M02 owns Agent Profile/Review semantics.
- M08 owns Dashboard/Notification projection semantics.
- M10 remains authorization authority.
- M01 authentication/activation is upstream WIRE-01.
- M03 Listing remains downstream WIRE-02.02+.

## Explicitly excluded
Listing CRUD/lifecycle, Listing creation wizard, Refresh, quota administration,
DBR/KPR workflow, Organization/Developer/Project, Commercial administration,
RBAC/Permission Preset administration, provider operations and shared-state
integration work are not absorbed into WF-02.01.

## Client/Admin
WF-02.01 contains **client/Agent screens only**. No Admin screen is invented.
The global WIRE foundation requires separate client/admin coverage when a package
actually contains both; here the authoritative source assigns Admin behavior to
later WIRE packages.
