# WIRE-02.05 v1.2 Screen Contract

| ID | Goal | v1.2 focus |
|---|---|---|
| AGT-011 | Manage a published Listing's current state and authorized actions | Preserve current scope and cover/media identity |
| AGT-012 | Edit an owned Listing while preserving immutable post-publish identity fields | Complete editable field surface; dependencies; conditionality; locks; long-scroll UX |
