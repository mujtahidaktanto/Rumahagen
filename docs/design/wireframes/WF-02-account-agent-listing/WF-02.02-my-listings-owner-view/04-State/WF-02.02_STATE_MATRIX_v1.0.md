| Screen | Ready | Loading | Empty | Error/Retry | Protected/Denied |
|---|---|---|---|---|---|
| AGT-003 My Listings | Yes | Yes | Yes | Yes | Yes |
| AGT-004 Owner View | Yes | Yes | N/A for existing-resource detail | Yes | Yes |

## State semantics
- Ready = authoritative data can be displayed.
- Loading = skeleton/placeholder, with no false business outcome.
- Empty = no listing inventory in the current context/filter.
- Error = retrieval failed; Retry is a presentation action.
- Protected/Denied = requested resource is not exposable in the current context/scope; no data leakage.
