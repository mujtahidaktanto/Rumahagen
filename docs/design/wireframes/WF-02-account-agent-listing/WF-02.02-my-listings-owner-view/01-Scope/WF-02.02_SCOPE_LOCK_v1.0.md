# WF-02.01 Scope Lock v1.1 — CORRECTED

## Exact scope
WF-02.01 covers the authenticated **Account + Agent Core** surface assigned to WIRE-02:
- AGT-001 Agent Dashboard
- AGT-002 Agent Profile

AGT-002 includes the complete M02 Agent Profile presentation scope that belongs in the
authenticated Agent surface: Profile, Profile Photo, Indonesian Profile Address,
Organization Name context, Profile Statistics, Profile Visibility/Public CTA,
Reviews presentation and Outcome Presentation.

## Boundary
M01 remains identity/authentication authority and is already represented in WIRE-01.
M10 remains authorization authority.
M03 remains Listing truth authority.
M12 remains Organization/Membership authority.
Upstream domains remain outcome owners.

## Not absorbed
Listing CRUD/lifecycle, Listing creation wizard, Refresh, quota administration,
DBR/KPR workflow, Organization/Developer/Project management, Commercial administration,
RBAC/Permission Preset administration, Provider/Ops and shared-state finalization remain
later WIRE scopes.

## Screen-count decision
AGT-002 remains one logical screen because these profile obligations are one coherent
user goal. It may use vertically scrollable sections and edit mode/progressive disclosure.
No requirement is deleted merely to preserve a small logical screen count.
