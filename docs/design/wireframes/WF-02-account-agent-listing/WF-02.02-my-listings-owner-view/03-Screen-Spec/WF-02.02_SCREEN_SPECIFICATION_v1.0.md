# WF-02.02 — Screen Specification v1.0

## AGT-003 — My Listings
**Goal:** find and open a listing owned by the current Agent context.

### Desktop
- Authenticated shell with collapsible sidebar.
- Page title + context.
- Primary “Create Listing” entry point only; its flow is later WIRE-02.03.
- Search field.
- Lifecycle filter chips: All, Draft, Published, Expired, Sold, Rented, Suspended.
- Sort control.
- Operational list/table with listing, status, context, updated information and Open action.
- Long result sets continue vertically; pagination/infinite scroll is an implementation option to be resolved later without changing the wireframe scope.

### Mobile
- Compact top bar.
- Stacked search and lifecycle filters.
- Listing cards instead of dense table rows.
- Open action per card.
- Vertical scrolling is normal.
- No forced horizontal table scroll.

### State renders
- Populated
- Empty
- Loading
- Error/Denied

## AGT-004 — Listing Detail — Owner View
**Goal:** understand the current authoritative listing state and access the next permitted listing operation.

### Desktop
- Status header.
- Media gallery.
- Listing identity and context.
- Property-identity lock presentation.
- State-aware action area.
- Activity/provenance summary.

### Mobile
- Status header.
- Media first, then identity/context.
- Action area after core understanding.
- Vertical scrolling.
- Progressive disclosure for secondary/provenance information.

### State renders
- Populated
- Restricted/protected
- Loading
- Error/retry

### Cross-module continuity
- AGT-003 Open → AGT-004.
- AGT-004 action entries may continue to later AGT-011/012/013/014/015 flows without embedding those flows here.
- Public discovery remains M11-owned.
- Commercial allowance remains M14-owned; Refresh action remains M03-owned; authorization remains M10-owned.
