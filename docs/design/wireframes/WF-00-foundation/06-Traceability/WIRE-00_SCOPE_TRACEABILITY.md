# WIRE-00 Scope Traceability v1.1

WF-00 covers foundation obligations that the current uploaded Core requires before detailed visual screen execution:

- authority/source precedence;
- source-only boundary;
- physical/runtime evidence stage boundary;
- explicit non-blocking rule for absent physical/runtime proof;
- IA/sitemap/navigation;
- desktop/mobile shell;
- screen decomposition and progressive disclosure;
- wizard/stepper and vertical-scroll rules;
- client/admin coverage separation;
- mandatory public discovery coverage (10 M11 surfaces);
- M14 commercial surface preservation (8 approved surfaces);
- M01–M15 downstream allocation;
- Listing-centered WIRE-02 placement;
- dynamic-content length handling;
- global state/error/loading/recovery vocabulary;
- accessibility/touch-target baseline;
- responsive/content-driven breakpoint rules;
- pagination/infinite-scroll strategy;
- typography hierarchy;
- security/privacy UX boundary;
- cross-module authority-preserving navigation;
- legacy UX preservation;
- do-not-invent rules;
- evidence annotation rules;
- WIRE-00→WIRE-11 scope boundaries.

Detailed module UI remains outside WIRE-00 and is executed only in its assigned WIRE package.
