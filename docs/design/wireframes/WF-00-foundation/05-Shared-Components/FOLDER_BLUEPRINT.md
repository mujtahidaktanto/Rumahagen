# Wireframe Folder Blueprint v1.1

Each WIRE work package uses:

```text
WIRE-XX/
├── desktop/
│   ├── client/
│   │   ├── screens/
│   │   └── states/
│   └── admin/
│       ├── screens/
│       └── states/
├── mobile/
│   ├── client/
│   │   ├── screens/
│   │   └── states/
│   └── admin/
│       ├── screens/
│       └── states/
├── shared/
│   ├── components/
│   ├── navigation/
│   ├── tokens/
│   └── states/
└── traceability/
```

Not every package must contain both client and admin folders, but whenever both exist they must remain separately auditable.

The uploaded RumahAgen logo is the canonical asset for the shell.
