## P Series

## Current vs superseded/history
No Step/P pack is moved to history solely due to chronology. Historical/superseded material that is embedded inside a current source pack remains inside that pack as provenance. The repository does not create a false current-vs-history split by extracting individual files out of their current parent pack.
