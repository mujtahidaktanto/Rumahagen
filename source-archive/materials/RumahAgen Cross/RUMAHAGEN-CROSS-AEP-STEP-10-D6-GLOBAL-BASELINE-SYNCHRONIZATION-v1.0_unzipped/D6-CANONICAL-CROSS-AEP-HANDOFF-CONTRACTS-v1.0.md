# RUMAHAGEN — D6 Canonical Cross-AEP Handoff Contracts v1.0

1. **Commercial → Learning:** Confirmed Payment → idempotent Purchased LP Grant.
2. **Commercial → Session:** Entitlement/authorization outcome → Session access; Payment is not the semantic definition of ACTIVE.
3. **Session → Learning:** Qualifying completion → Learning Activity boundary → Learning Economy; MADCR-049 remains conditional.
4. **Learning → Awarding:** Learning/assessment/LP/credential/partner evidence → Awarding Qualification according to Path/Rule.
5. **Session → Awarding:** Session completion evidence → Qualification; Session cannot issue Award directly.
6. **RBAC → all domains:** Role + Capability Permission + applicable Authority/Scope → authorization.
7. **Provider → Session:** Provider event → validation → normalization → idempotency → evidence → evaluation.
8. **Event Calendar → Session:** discovery/presentation/integration context → semantic Learning Session; Event is not Session authority.
